about.md

Engineer with a designer's eye

I like the space where code meets craft. On the front end I care about motion, typography and accessibility. On the back end I care about clear API contracts, sensible data models and queries that stay fast as data grows.

My best work happens on small, product-minded teams: I'll pair with a designer on Monday, write a migration on Tuesday, and ship the feature behind a flag by Friday. I document what I build so the next person can move quickly too.

Performance first Budgets for bundle size, Core Web Vitals and query time.
Accessible by default Semantic HTML, keyboard paths and WCAG AA contrast.
Clear communication Readable PRs, written specs and honest estimates.
